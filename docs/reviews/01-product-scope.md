# 产品范围与版本边界

评审状态：待评审

## 目标

Blink 是面向 Kubernetes、K3s 和边缘 AI 推理工作负载的轻量对象存储。首个可用版本优先解决边缘节点内的模型和推理数据读写，不以完整替代公有云对象存储为目标。

## 首个可用版本范围

- 单实例本地持久化。
- 基础 Bucket 和 Object 生命周期。
- 大对象上传、下载、范围读取和删除。
- 常用 S3 客户端的基本互操作。
- 明确的启动配置、健康检查和结构化日志。
- Docker 与 Kubernetes / K3s 的开发部署样例。
- 可重复的功能、故障恢复和性能基准测试。

## 暂不纳入首个版本

- 多副本强一致分布式存储。
- 跨区域复制和完整云边同步编排。
- 复杂多租户计费与配额系统。
- 面向互联网暴露的完整安全合规体系。
- 未经基准测试支持的性能承诺。

## 验收问题

- 首个版本的最小硬件配置是什么？
- 需要兼容哪些 S3 SDK 和客户端？
- 单节点故障恢复的目标时间和数据保证是什么？
- 首个版本的最大对象大小、Bucket 数量和并发目标是什么？
