# 产品范围与版本边界

评审状态：已允许开发
评审人：binbinpeng123
评审日期：2026-10-23
适用版本：v0.1.0（首个可用版本）

## 目标

Blink 是面向 Kubernetes、K3s 和边缘 AI 推理工作负载的轻量对象存储。首个可用版本优先解决边缘节点内的模型和推理数据读写，不以完整替代公有云对象存储为目标。

三条不可妥协的产品约束：

1. **边端部署方便**：单静态二进制，无外部数据库、无运行时依赖。
2. **资源占用轻**：空载时内存与磁盘占用可预期，不引入后台常驻的大型组件。
3. **读写极快**：针对"大模型权重顺序/分段读取"与"小对象批量写入"两类真实负载优化，且**必须由 benchmark 数据支撑**。

## 首个可用版本范围

- 单实例本地持久化。
- 基础 Bucket 和 Object 生命周期。
- 大对象上传、下载、范围读取和删除。
- 常用 S3 客户端的基本互操作。
- 明确的启动配置、健康检查和结构化日志。
- Docker 与 Kubernetes / K3s 的开发部署样例。
- 可重复的功能、故障恢复和性能基准测试。

## 暂不纳入首个版本

- 跨区域复制和完整云边同步编排。
- 复杂多租户计费与配额系统。
- 面向互联网暴露的完整安全合规体系。
- 未经基准测试支持的性能承诺。
- S3 的 ACL、Tagging、Lifecycle、Versioning、Replication、Object Lock 等高级特性（显式返回 `501 NotImplemented`，不得静默忽略）。
- 非标准扩展 API（批量写、pin/预热接口）。

## 分布式能力（v0.2.0）

**v0.1.0 是单节点设计，v0.2.0 在同一二进制内加入集群模式。** 详细设计见 [08 分布式存储设计](./08-distributed-storage.md)。

| 能力 | v0.2.0 范围 |
| --- | --- |
| 跨节点读写 | 任意节点接收 S3 请求，按一致性哈希扇出到 N 个副本 |
| 多副本 | 默认 `N=3, W=2, R=2`，`W+R>N` 保证 read-after-write |
| 纠删码 | 可选，`2+1`（3 节点）/ `4+2`（≥6 节点），默认关闭 |
| 成员管理 | **静态成员表**，无发现、无 gossip、无共识 |
| 再平衡 | **不做自动再平衡**；提供离线 `blink-admin rebalance` |
| 故障修复 | 读修复 + 持久化修复队列 + 周期反熵 |

**明确不做**：节点发现、成员变更、共识协议（Raft 等）、跨区域复制、EC 自动换组重编码。

**单机模式是默认路径且必须零回归**：不启动内部端口、不启动修复 goroutine、不引入额外函数调用跳转。`store.Backend` 接口只改变依赖方向，不改变单机实现。

## 关键参数

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 单次 PUT 上限 | 5 GiB | 超出须使用分片上传，与 S3 一致 |
| 单对象上限 | 5 TiB（软上限） | 实际由磁盘容量决定 |
| Bucket 数量 | 1000（软限制，可配） | 防止误用，不阻碍边端场景 |
| 默认块大小 | 4 MiB | 见 03 文档 |
| 小对象内联阈值 | 64 KiB | 见 03 文档 |
| 默认端口 | 9000 | 可用 `--addr` 覆盖 |
| 默认数据目录 | 二进制 `./blink-data`；容器 `/var/lib/blink` | 可用 `--data-dir` 覆盖 |
| S3 区域 | `us-east-1` | 可配置 |
| 集群副本数 N / W / R | `3 / 2 / 2` | 启动校验 `W+R>N`，否则拒绝启动 |
| 集群节点数上限 | 12（v0.2.0 建议值） | 静态成员；LIST 成本随节点数线性增长 |
| 内部端口 | `9100` | 仅集群内网，HMAC 认证 |
| EC profile | `2+1`（3 节点）/ `4+2`（≥6 节点） | 默认关闭，对象 ≥32 MiB 才启用 |

**并发与延迟目标**不写入本版本的产品承诺，只在 05 文档中作为绑定具体硬件的回归基线存在。

## 客户端兼容矩阵

| 客户端 | 状态 | 说明 |
| --- | --- | --- |
| AWS CLI 2.x | 必须通过 | 首个版本的互操作验收基准 |
| 任意 SigV4 SDK | 应通过 | 协议层兼容，按 02 文档的接口契约验收 |
| MinIO Client (`mc`) | **待验证** | 开发环境未安装，不得声称已通过 |
| s3fs / rclone | 待验证 | 不在首个版本验收范围 |

## 验收问题与结论

- **最小硬件配置**：单核、512 MiB 内存、1 GiB 可用磁盘可运行并完成基本读写；这是"可启动"下限，不是性能承诺。
- **需要兼容哪些 S3 SDK 和客户端**：以 AWS CLI 为硬性基准，协议层按 SigV4 与 S3 XML 契约实现，其余 SDK 以通过测试为声明依据。
- **单节点故障恢复目标**：进程崩溃或重启后数据不丢失、不残缺；恢复时间与已存对象数量**弱相关**（启动不做全量扫描）。
- **最大对象大小、Bucket 数量与并发目标**：见上表；并发目标不设产品承诺，只在 05 文档绑定硬件记录基线。
