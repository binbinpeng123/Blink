# 测试与性能基准

评审状态：待评审

## 测试层次

- 单元测试：元数据、布局、校验和、错误处理。
- 集成测试：S3 API、文件系统、重启恢复。
- 互操作测试：AWS CLI、MinIO Client 和至少一种主流 SDK。
- 故障测试：进程中断、磁盘满、对象损坏、并发冲突。
- 部署测试：Docker、Kubernetes 和 K3s。
- 性能测试：小对象、模型大对象、范围读取、并发读写。

## 记录指标

- 首字节延迟和完整对象读取延迟。
- 上传和下载吞吐、P50/P95/P99 延迟。
- 不同对象大小与并发数下的 CPU、内存、磁盘 I/O。
- 重启恢复耗时和恢复后的数据完整性。

## 验收原则

性能目标必须绑定硬件、对象大小、并发数和测试工具版本。没有可复现实验条件的数字不能作为项目承诺。
