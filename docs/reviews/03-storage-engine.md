# 本地存储引擎设计

评审状态：待评审

## 目标

为单节点边缘部署设计可恢复、可校验、适合大对象顺序读写的本地数据布局和访问路径。

## 待定义内容

- Bucket、Object、元数据和数据块的目录或索引布局。
- 小对象与大对象的存储策略及分片大小。
- 并发读写、覆盖写、删除和垃圾回收规则。
- 写入落盘、崩溃恢复和启动扫描流程。
- 校验和、损坏检测和错误报告。
- 磁盘容量水位、保留空间和满盘行为。
- 临时文件、原子提交和重启后的清理策略。

## 验收要求

设计必须给出数据损坏、进程中断、磁盘满和重复写入时的行为；实现必须有恢复测试、并发读写测试和可观测的失败原因。
