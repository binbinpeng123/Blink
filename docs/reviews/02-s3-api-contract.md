# S3 接口与数据模型

评审状态：待评审

## 目标

定义 Blink 首个版本对外暴露的 S3 兼容边界，避免客户端、服务端和测试对行为产生不同理解。

## 待定义内容

- Bucket 创建、查询、删除和命名约束。
- Object 的 PUT、GET、HEAD、DELETE 和 LIST 行为。
- Range 请求、分片上传和并发上传语义。
- `Content-Type`、ETag、Last-Modified、Metadata 等属性。
- 认证签名版本、错误码和 HTTP 状态码。
- 读写一致性、覆盖写和删除后的可见性。
- 不支持的 API 及其明确错误响应。

## 验收要求

每个支持的 API 都应有请求示例、响应示例、错误示例和自动化互操作测试。兼容性声明只能基于通过测试的 API 发布。
